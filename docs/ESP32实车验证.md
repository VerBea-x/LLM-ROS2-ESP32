# ESP32小车：下一步现场验证

仿真结果不能证明下列能力。目前没有向小车发送运动指令。

2026-10-26用户确认：现有ESP32小车没有摄像头。当前实车验证只安排通信、运动、停车及固件实际发布的传感器；视觉部分采用已授权的20张公开室内图离线替代实验，不安排ESP32相机接入。

1. 在车旁确认固件版本、连接方式、电源和可立即断电的方法。先抬起车轮或清空低速测试区域。
2. 启动与当前固件匹配的micro-ROS agent，先只读盘点实际话题。在ROS终端运行 `python3 scripts/probe_esp32_readonly.py --output evidence/raw/esp32_graph.json`。使用小车实际通信域，不使用本项目47/48/49/50仿真域。
3. 对真实发布的odom/imu话题检查类型、时间戳更新和频率。没有发布的项目保留未验证，不能用示例代码代替。
4. 确认cmd_vel单位、限速、控制超时和停车机制后，再安排短时最低速度直行、转向、零速停车，记录轮子动作和停下时间；先试停车，再做动作。现场条件确认前不运行自动运动脚本。
5. 第5周已采用20张公开室内图完成离线替代评测；第6周用受控合成检测验证语义地图，不要求小车相机。公开图像和模拟结果不能计作相机部署或标定通过。
6. 无真实雷达，不做实车激光建图、激光避障或真实AMCL定位验收。

记录表最少字段：固件/连接方式、话题/类型、帧时间戳、命令及持续时间、测量方法、真实运动/停车结果、录像文件、异常与局限。
