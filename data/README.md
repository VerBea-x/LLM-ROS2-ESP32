# 数据目录

- `coco_indoor20_v2/images/`：当前采用的20张公开室内场景。
- `coco_indoor20_v2/dataset.json`：独立标注、场景复核、原图哈希、来源与许可信息。
- `coco_indoor20_v2/scene_contact_sheet.jpg`：当前选图总览。
- `annotations/instances_val2017.json`：共享的COCO官方验证集标注。
- `annotations/annotation_source.json`：官方ZIP来源、成员名及校验信息。
- `active_vision_dataset.json`：当前数据版本的索引。

旧通用图片集已退役；它的标注与筛选记录保存在 `../archive/vision_v1/`。候选图片筛选记录见 `../archive/indoor_selection/`。
