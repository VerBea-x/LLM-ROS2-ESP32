# 第6周受控语义地图验证

结论：无需真实摄像头，已通过实际ROS受控合成检测链的10项检查；登记记录进入审计器的新鲜/过期回归6/6。来源是模拟检测与模拟移动，不是现场相机或公开照片的真实定位。

实验版本与协议：[冻结协议](../../config/week6_controlled_lab_protocol.json)、[有效原始记录v3](../raw/week6_ros_lab_v3/lab_result.json)。两个早期运行因重复节点使唯一订阅检查失败，在检测注入前中止；其空地图不能算完成，RUN_STATUS保留。有效v3运行后已停止实验节点。

| 检查 | 结果 |
|---|---|
| 正前方坐标误差≤5cm | 通过 |
| 左/右检测分别对应y增/减 | 两项通过 |
| 同杯两次只合并成一个，n_obs=2 | 通过 |

| 不匹配的CameraInfo分辨率拒绝 | 通过 |
| 10秒前检测时间戳拒绝 | 通过 |

实际接口为Detection2DArray、CameraInfo、TF、MarkerArray和JSON；不是仅执行几何函数。使用虚拟640×480内参，固定1m距离近似，检测阈值引用第5周选择0.5。类别backpack只测注入接口，没有对应第5周检测精度结论。

τ从seed601的合成移动日志前300逻辑秒推导：人1.5秒、手持物4秒、家具15秒。原始600逻辑秒事件与训练事件数保存于[移动日志](../raw/week6_controlled_mobility.json)，规则保存于[配置](../../config/week6_controlled_tau_rules.json)。不是实际等待600秒，也不是实地移动规律。

误差试算表明，固定估距1m时，0.8m目标径向误差+20cm，2.5m目标径向误差-150cm；5像素偏置的切向误差约1.56cm。这说明单目距离近似是主要局限，不应把理想正前方成功推广到任意距离。[四例误差分解](week6_controlled_error_components.json)。

[桥接回归](week6_to_week8_auditor_bridge.json)读取记录下来的3个目标，使用各快照自己的时钟；新鲜时3个允许，过期时3个按R2拒绝。没有模型调用或导航执行；查图使用已知地图仿真快照，资源仍为明确模拟值。

复现：项目目录运行`bash scripts/run_week6_lab.sh`，使用新输出目录；需要ROS运行权限。仅合成检测消息，不发布电机命令。原始v3结果不覆盖。完整课程范围、待补实景站位与相机条件见[第6周交付](../../docs/weeks/week06.md)。
